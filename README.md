# Recruiter Offer Modeling Tool

A simple, visual offer modeling tool that helps recruiters see the full pay story — base salary plus equity vesting — in one clean view.

---

## 🚀 Purpose
Recruiters often need to explain how base salary and equity combine into total compensation. This tool provides an interactive way to model offers and visualize the total 4-year picture.

---

## 🧩 Inputs
- Base Salary (USD)
- Estimated Start Date
- Equity Grant Type (e.g., New Hire RSU)
- Grant Value or Units
- Vesting Schedule

---

## 📊 Outputs
- Total Compensation Visualization (Base + Equity by year)
- Cumulative 4-year total
- Vesting timeline chart

---

## 🛠️ Roadmap
**v1:** Base + Equity visualization for a single job profile  
**v2:** Add multiple job profiles, cash bonus inputs, export options  
**v3:** Add comparison scenarios (e.g., different start dates or grant values)
